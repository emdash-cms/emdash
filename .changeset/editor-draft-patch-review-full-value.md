Shows the whole value when you review a sandboxed plugin's proposed editor changes. "Before" and "After" previously showed only the text of a rich text field, cut at 160 characters, so an added HTML block, image or embed, a changed link target, or an edit further down did not appear. The review now lists every block, including link targets and blocks without text, and shows other values in full instead of truncating them.
