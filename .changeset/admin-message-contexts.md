Fixes admin labels that a language couldn't translate differently from another label with the same English word: the **Select** field type (shared with the **Select** button), the **Admin** sidebar heading (shared with the **Admin** user role), and **Authors** for user accounts on the site import review (shared with plugin **Authors**). Each can now be translated on its own, and shows in English until a language translates it.
