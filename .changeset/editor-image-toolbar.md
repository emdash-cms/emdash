Adds a toolbar above a selected image in the Portable Text editor, with Replace, Alt text, alignment (None, Left, Center, Right), Link, Image settings, and Delete. It replaces the buttons in the image's corner. Captions are typed directly under the image: an empty caption shows a placeholder, and Enter starts a new paragraph after the image. The alt text button reads **Add alt text** when an image has no description or, for a Media Library image, only its file name. The image settings panel now closes when the image is changed outside it, discarding edits that weren't applied, so **Apply** no longer overwrites those changes.
