Updates the admin's list pages to share one page header. The Dashboard, content lists, Users, Bylines, Byline schema, Menus, Categories, Tags, Sections, Widgets and Content Types pages now lay out the title, description and actions the same way, and show each page's main action as the primary button. Search and filters sit in the header right after any tabs, on these pages and on Comments, Redirects and Calendar. On Categories and other taxonomy pages, "New taxonomy" has moved into the "More actions" menu, as on Tags. On content lists, setting a filter no longer moves the filters or the table.
