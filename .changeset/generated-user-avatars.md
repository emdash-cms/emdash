Adds generated avatars for users without a profile picture. The header, the **Users** list and the user detail panel show a colorful avatar with the user's initials, chosen from their user ID so each user looks the same everywhere. Users without a name show the avatar without letters instead of their email's first letter. On phones, the header's user menu button is now named after the user for screen readers.
