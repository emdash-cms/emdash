Revision history now shows changes inside blocks and repeater fields. A version's change list names each block that was added, removed or moved, and each field edited inside a block, such as "Edited Headline in the Hero block", instead of a single "Changed Content" entry. Selecting an entry scrolls to that block or field. The read-only version shows blocks and repeater items as cards with all their fields, marks edits inside the fields that changed the same way as top-level fields, and dims removed items in place. A block type upgrade that changes no values isn't reported as a change.
