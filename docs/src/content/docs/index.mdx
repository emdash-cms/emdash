EmDash runs as part of your Astro application. Editors create and publish content in the built-in
admin panel. Your Astro pages read the published content when they render, so an editor's changes
can appear without rebuilding the site.

EmDash includes collections and fields, draft and publishing workflows, rich text, media,
taxonomies, menus, widget areas, previews, and plugins. You can run it on Node.js or Cloudflare
Workers.
