Run the Node.js and SQLite demo to start working on EmDash locally. [CONTRIBUTING.md](https://github.com/emdash-cms/emdash/blob/main/CONTRIBUTING.md) is the canonical source for prerequisites, repository layout, contribution policy, checks, changesets, and pull request requirements.

## Set up the repository

<Steps>

1. **Clone, install, and build the workspace.**

   ```bash
   git clone https://github.com/emdash-cms/emdash.git
   cd emdash
   pnpm install
   pnpm build
   ```

2. **Start the primary development demo.**

   ```bash
   cd demos/simple
   pnpm dev
   ```

3. **Open the development bypass URL.**

   Visit [the local setup bypass](http://localhost:4321/_emdash/api/setup/dev-bypass?redirect=/_emdash/admin). It runs migrations, creates a development administrator, signs you in, and redirects to the admin panel. To test the passkey setup flow instead, open [the admin panel](http://localhost:4321/_emdash/admin).

</Steps>

The demo applies `seed/seed.json` automatically on its first request when the database is empty.

## Develop against `packages/core`

Run the core package watcher and the demo in separate terminals so core changes rebuild automatically:

```bash
# Terminal 1
cd packages/core && pnpm dev

# Terminal 2
cd demos/simple && pnpm dev
```

Before opening a pull request, follow the [checks and contribution policy in `CONTRIBUTING.md`](https://github.com/emdash-cms/emdash/blob/main/CONTRIBUTING.md). For documentation changes, also follow the [documentation style guide](/contributing/docs-style-guide/). Translation contributions have a separate [translation workflow](/contributing/translating/).
