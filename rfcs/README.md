# Legacy EmDash RFCs

New feature plans and RFCs use the design process in [`proposals/`](../proposals/README.md). The numbered RFCs in this directory predate that process and keep their existing paths as historical records.

Do not allocate another numbered RFC. Amend or supersede an existing RFC through a design pull request under the current proposal process.

- [RFC 0002: Attested automated publishing](./0002-attested-automated-publishing.md)
